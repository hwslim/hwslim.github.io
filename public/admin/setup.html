최초 로그인 연결

사이트는 GitHub Pages에서 운영하고, Cloudflare Workers는 GitHub 로그인 인증만 처리합니다. Python 서버는 필요하지 않습니다.

  1. Cloudflare 계정을 만들고 Workers & Pages에서 erilab-auth Worker를 생성합니다.
  2. 저장소의 auth-worker/worker.mjs를 Worker 코드에 넣어 배포합니다.
  3. GitHub Settings → Developer settings → OAuth Apps에서 앱을 등록합니다. Homepage URL은 https://erilab.xyz, Callback URL은 Worker주소/callback입니다.
  4. Worker의 변수에 GITHUB_CLIENT_ID, SITE_ORIGIN=https://erilab.xyz, REPO=hwslim/hwslim.github.io를, Secret에 GITHUB_CLIENT_SECRET을 등록합니다.
  5. public/admin/config.json의 backend.base_url에 Worker 주소(https://…workers.dev, 끝의 / 제외)를 저장합니다. 자동 배포가 완료되면 관리자 페이지에서 GitHub로 로그인합니다.

관리자는 저장소 쓰기 권한이 있는 GitHub 계정입니다. 회원가입 화면과 별도 admin/admin 계정은 사용하지 않습니다. 비밀번호 변경은 GitHub 계정 설정에서 합니다.
