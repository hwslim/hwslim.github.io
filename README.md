# ERILab — GitHub Pages

Embodied Robot Intelligence Lab, KIST Center for AI Research. Existing lab layout and public content migrated to the `hwslim/hwslim.github.io` Next.js static export project.

- Public pages: Home, Research, People, Publications, News, Contact.
- Legacy routes `/researchers/`, `/research-areas/`, `/projects/` show the corresponding People/Research pages.
- Homepage: research, Latest News, latest three publications; people are on the People page.
- People: PI, Researchers, Interns, three student programs, Alumni. Student headings use `Name (School)` when a school is provided. Researchers automatically sort by rank. Alumni show only name and destination.
- Optional CV website/PDF, photos, email, schools, fixed-choice role/degree controls, and independent technical-service switch.
- Publications: year groups, links, only Oral/Spotlight highlight badges.
- Responsive CSS from the local site is retained.

## Local preview

Use Node.js 22 and pnpm 10, matching GitHub Actions.

```bash
npx --yes pnpm@10 install --frozen-lockfile
npx --yes pnpm@10 dev
```

Open `http://localhost:3000`. For the actual static Pages artifact:

```bash
npx --yes pnpm@10 build
python3 -m http.server 8001 --bind 127.0.0.1 --directory out
```

Open `http://127.0.0.1:8001`. Python here is only an optional local file preview; it is not part of site hosting.

## Web editing and one-time login setup

Admin is `/admin/`, powered by Decap CMS pinned to version 3.16.3. Content lives in `content/`, uploaded media in `public/uploads/`. Saving commits to `main`; GitHub Actions validates, builds, and deploys the new static site.

**GitHub OAuth setup is pending.** Until `backend.base_url` is configured, Admin displays setup instructions. Follow [the Korean setup guide](docs/ADMIN_SETUP.md) to create a Cloudflare Worker and GitHub OAuth app. The worker only handles authentication; hosting remains on GitHub Pages with the existing domain.

Administrators sign in with GitHub accounts with repository write access. There is no signup or separate admin/admin account. Password changes happen in GitHub settings.

Alumni movement clears active profile fields before saving. Unreferenced uploads/profile media are omitted from the public build. Previously public files may still exist in GitHub history; see the setup guide.

## Deployment

The existing `.github/workflows/deploy.yml` builds changes and automatically deploys `main` to GitHub Pages. Pull requests run the checks/build without deploying. `public/CNAME` remains `erilab.xyz`.

See [migration and deployment handoff](docs/MIGRATION.md) for the local branch, validation, and remaining external setup. `out/` is generated by Actions and is not committed.

## Verification

```bash
npx --yes pnpm@10 test
npx --yes pnpm@10 validate
npx --yes pnpm@10 build
```

Tests cover ordering, editing rules, Alumni sanitization, CV/link validation, supported publication highlights, admin initialization, and the OAuth state/popup/repository permission protocol. OAuth network responses are mocked in tests. Live login and CMS commits must be verified after account setup.

The initial migration exported 9 people, 2 research topics, 41 publications, 0 news entries and 5 referenced images from the local database. Audit sources are in `docs/sources/`. The original Scholar list could not be fully compared because access was blocked; only the previously verified KIST records were migrated. Source audits describe the initial import; later CMS content is authoritative.

The original Flask SQLite database, credentials, session key and private instance folder are not part of this repository.
